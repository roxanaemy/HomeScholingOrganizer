How to Use

Quick guide to the Homeschool Family Organizer demo.

1. Students

Review each child’s grade, age, subjects, learning days and instruction hours.

2. Curriculum & Planner

Curriculum tracks completion; Planner shows planned lessons for each student.

3. Daily Log

Daily Log records what actually happened and feeds the dashboard activity, streak and weekly progress.

4. Grades & Attendance

Grades and attendance are tracked separately so academic performance is not mixed with instructional records.
