How to Use

A simple workflow for keeping your homeschool records organized.

1. Add your students

Add each child with their grade level, age, and homeschool start date.

2. Add subjects

Create each subject for the correct student and optionally record the curriculum and learning objectives.

3. Log learning

Select a student and one of that student's subjects, then record the date, duration, and what was completed.

4. Record grades

Select the student and subject, then record the assignment or assessment and score.

5. Review progress

The dashboard and Progress tab summarize learning activity and grades.
